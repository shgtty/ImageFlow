# ImageFlow

**ImageFlow** は、指定したローカルフォルダや ZIP ファイル内の画像および動画を自動的に収集し、無限スクロールのデジタルサイネージやスライドショーのように滑らかに表示させることができる軽量な Web アプリケーションです。

## ✨ 主な機能

- **動画再生（MP4）に対応**:
    - 画像（`.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`）に加えて、動画（`.mp4`）の読み込み・再生に対応。
    - サーバー側の Range リクエスト（Partial Content）対応により、大容量の動画もスムーズにストリーミング再生。
    - ミュート再生、自動再生、ループ再生をサポート。マウスホバー時にはシークなどのコントロールバーが表示されます。
- **2つの表示モード（モード別リスト保持）**:
    - **ギャラリーモード**: 無限スクロールで多くの画像・動画を一覧表示します。デジタルフォトフレームや店舗サイネージに最適です。
    - **デュアルビューモード**: 2枚の画像・動画を画面いっぱいに左右に並べて表示します。自動送り（スライドショー）機能付き。
    - モードごとに独立したファイルリストおよびソート順を保持し、切り替え時もストレスなく鑑賞を継続できます。
- **インテリジェントなデュアルビュー**:
    - 画像・動画の縦横比を維持しながら、画面いっぱいに大きく表示します。
    - **横長のメディア（風景写真やワイド動画など）を検出すると、自動的に1枚のみを大きく表示**するスマートレイアウト機能を搭載。
    - メディア切り替え時の自然なアニメーションを搭載。
- **滑らかな無限オートスクロール**: ギャラリーモードでは数千枚のメディアをスムーズに流し続け、一番下まで到達するとシームレスにループします。
- **ZIP ファイルの直接読み込み**: ディレクトリ内の ZIP を自動検出し、メモリ上でオンデマンドに展開して画像・動画をストリーミング表示します。
- **フォルダ・ZIP内フォルダ一覧ドロワー**:
    - 画面左端へのマウスホバーや `D` キーでスライドイン表示。
    - 各フォルダ（ZIP内サブフォルダ含む）の先頭画像サムネイルおよび含まれるメディア枚数を一覧表示。
    - フォルダ名・アーカイブ名のインクリメンタル検索に対応。
    - ドロワーの**ピン留め（固定表示）**機能。
    - 任意のフォルダをクリックして、その先頭メディアへ瞬時にジャンプ。
- **柔軟なソート機能**:
    - **ランダム**: すべてのメディアをシャッフル（ギャラリーモードのデフォルト設定）。
    - **フォルダ単位ランダム**: フォルダ（ZIP内サブフォルダ含む）内の順序を維持したまま、フォルダ自体の表示順をランダム化。
    - **ファイル名昇順**: ファイル名基準でソート（デュアルビューモードのデフォルト設定）。
- **フォルダ対応シークバーナビゲーション**:
    - `S` キーで表示切り替え可能なシークバー。
    - 昇順およびフォルダ単位ランダム表示時には、現在表示中のフォルダ（またはZIP内フォルダ）に合わせた枚数・現在位置をシークバーおよびツールチップへ直感的に反映。
    - `PageUp` / `PageDown` キーによる前後フォルダへのダイレクトスキップ。
- **多機能なフィルターと加工**:
    - **高度なフィルター設定**: UIのモーダルからキーワードを動的に追加・削除可能。AND/OR モードの切り替えや、有効なキーワードを上位に表示する自動ソート機能を搭載。
    - **色モード**: グレイ、セピア、ネガティブ、高コントラストに加え、**高彩度**、**ぼかし**、**ドット絵（Pixel art）**、**ブラウン管（CRT）**などの多彩なリアルタイムフィルタ。`Shift` + `C` による逆順送りにも対応。
- **高機能なブックマークシステム**:
    - 気に入った画像・動画に星マークを付けてブックマーク可能。
    - **ブックマーク頭出し（スキップ）**: `Tab` / `Shift` + `Tab` キーで、ブックマークされたファイルだけを順に素早く辿ることができます。
    - **CSV形式での保存**: ブックマークデータは CSV 形式（`bookmarks.csv`）で保存され、他ツールでの二次利用や軽量なデータ管理を実現。
    - **多機能なブックマークモーダル**:
        - **サムネイル表示（グリッドビュー）**: リスト表示に加え、サムネイル付きのグリッド表示に対応。
        - **フォルダ・設定単位でのグループ化**: アコーディオン形式でフォルダごとにブックマークをグループ化し、展開・折りたたみが可能。
        - **ソート＆検索**: ブックマークしたファイル名でのソート（昇順・降順）や、任意のキーワードによる絞り込み。
        - **ジャンプ機能**: ブックマークをクリックすると、その画像・動画の位置まで瞬時に移動。
        - **一括削除**: モーダル上からブックマークをすべてクリアできます。
- **動的な設定ファイル切り替え・複数選択と直接編集**:
    - UIモーダルから複数のテキスト設定ファイルをシームレスに切り替え可能。
    - **複数選択対応**: チェックボックスにより複数の設定ファイルを一括選択し、まとめてメディアを読み込むことが可能。選択中のファイルは上部にバッジ表示されます。
    - **モードごとの個別保存**: ギャラリーモードとデュアルビューモードそれぞれで最後に選択した設定ファイルを記憶。
    - **内蔵エディタ**: 切り替えるだけでなく、設定ファイルをブラウザ上で直接編集・保存が可能。
- **没入型UIと状態の永続化**:
    - **スマートUIオートハイド**: 操作がないと、コントローラー、マウスカーソル、および**カーソルツールチップ（ファイル名表示）**が自動的にフェードアウトします。
    - **ステータスオーバーレイ**: マウス移動や操作時に、画面上部に現在の表示モード、ソート順、メディア枚数、適用中の色モード、選択されている設定ファイル名、フィルター状態などを美しく一目で確認できるオーバーレイがリアルタイムに表示されます。
    - **シームレスな位置復元**: モード切替時やウィンドウのリサイズ時、表示していた画像・動画の位置を自動的に特定し、文脈を維持したまま表示を継続します。
    - **フルスクリーンソフトリロード**: 全画面表示中に `F5` または `Ctrl` + `R` を押すと、フルスクリーンを解除せずにメディアリストを再取得します。
    - **カウントダウンプログレス**: 次の画像への切り替えタイミングを視覚的に表示。
    - **カーソルツールチップ**: マウスカーソルの横に、現在の画像の「フォルダ名 > ファイル名」を動的に表示。スライドショー非再生時（一時停止中）にマウスが停止すると自動的に非表示になり、没入感を妨げません。
- **直感的な設定画面 (Settings Screen)**:
    - `P` キーまたは画面上のボタンから設定画面を開き、各種オプション（表示モード、ソート順、スクロール速度、カラム数、スライドショー間隔、色モード、フィルター有効化、カーソルツールチップの表示有無など）をダイレクトに変更可能。
    - 全ての設定をワンクリックで初期値に戻すリセット機能も搭載。
- **設定の自動保存**: スクロール速度、列数、表示モード、各種フィルター設定などはブラウザを閉じても次回起動時に自動で復元されます。

## 🚀 起動方法

1. **事前準備**: お使いの PC に [Node.js](https://nodejs.org/) がインストールされている必要があります。
2. 本フォルダ内にある `start_server.bat` をダブルクリックして実行します。
3. 自動でサーバーが起動し、既定のブラウザで `http://localhost:8000` が開きます。

## 🎮 操作方法

### 共通の操作
- `Enter` キー / **画面ダブルクリック** / **マウス中クリック（ホイール押し込み）**: フルスクリーン（全画面）表示の切り替え。
- `F5` キー / `Ctrl` + `R` (Mac: `Cmd` + `R`): フルスクリーン表示中に全画面を解除せず画像リストを再読み込み（ソフトリロード）。
- `M` キー: ギャラリーモードとデュアルビューモードの切り替え。
- `R` キー: ソート順（ランダム / フォルダ単位ランダム / 昇順）の切り替え。
- `Space` キー: 動作（スクロールまたは自動送り）の「一時停止 / 再開」。
- `S` キー: 画面下部シークバーの表示切り替え。
- `C` キー / `Shift` + `C` キー: 色モード（フィルタ）の順送り / 逆送り切り替え。
- `I` キー: カーソル横のファイル名表示（カーソルツールチップ）の切り替え。
- `F` キー: **フィルター設定モーダル**の表示。キーワードの追加やAND/OR切り替えが可能です。
- `B` キー: **ブックマークモーダル**の表示。サムネイル一覧、フォルダ別グループ化、検索・ソート、一括削除機能に対応し、お気に入りの画像を一覧で確認・移動できます。
- `D` キー: **フォルダ一覧ドロワー**の表示切り替え（画面左端へのマウス移動でも自動スライドイン表示されます。ピン留めによる固定も可能）。
- `P` キー: **設定画面（Settings Screen）**の表示切り替え。
- `Tab` キー / `Shift` + `Tab` キー: 次のブックマーク / 前のブックマークへ移動（頭出し）。
- `PageUp` / `PageDown` キー: 前のフォルダ / 次のフォルダへ移動（昇順ソートまたはフォルダ単位ランダム時）。
- `0` キー: すべての設定（表示モード、ソート順、色モードなど）を初期値にリセット。
- `ESC` キー: **モーダルやドロワーを閉じる**、通常表示に戻る、またはフルスクリーンを解除します。通常ウィンドウ時ならアプリケーションを終了します。
- **マウス操作**:
    - **画面左端へのホバー**: 画面左端からフォルダ・ZIP内フォルダ一覧（先頭画像サムネイル付き）がスライドイン表示されます。
    - 画面上でマウスを動かすと操作パネルやステータスオーバーレイが表示されます。

### ギャラリーモード
- `↑` / `↓` キー: スクロール速度の加速 / 減速。
- `←` / `→` キー: 画像・動画の列数（カラム数）の変更（←で減少、→で増加、1～10列）。
- `PageUp` / `PageDown` キー: 前のフォルダ / 次のフォルダへ移動（昇順ソートまたはフォルダ単位ランダム時）。

### デュアルビューモード
- `←` / `→` キー: 1枚ずつ前の画像 / 次の画像へ移動（動画要素の上をクリックした場合は、動画のシーク等のコントロールが優先されます）。
- `↑` / `↓` キー / **左右クリック（メディア要素外）** / **マウスホイール回転**: 前のページ / 次のページへ移動。
- `Home` / `End` キー: 最初の画像 / 最後の画像へ移動。
- `PageUp` / `PageDown` キー: 前のフォルダ / 次のフォルダへ移動（昇順ソートまたはフォルダ単位ランダム時）。
- `O` キー: 表示方向（左から右 / 右から左）の切り替え。
- 操作パネルの `+` / `-` ボタン: 自動送りの間隔（秒数）を変更。

## 📝 設定ファイル

`config` フォルダ内にある設定ファイルを直接編集するか、アプリケーションのUI上からカスタマイズできます。
※ 行頭に `#` を付けるとコメントとして無視されます。

### 1. `config/folders.txt`
読み込みたいフォルダのフルパスまたは ZIP ファイルのパスを1行ずつ記述します。
* 例：`C:\Users\User\Pictures`
* 例：`D:\Archives\TravelFiles.zip`

※ デュアルビュー専用の設定ファイルとして `config/dual_folders.txt` を配置することも可能です。配置されている場合、デュアルビューモード初期起動時のフォールバックとして優先的に使用されます。

### 2. `config/include.txt`
表示したい画像・動画に含まれるべき文字列を記述します。
* `MODE:AND` (デフォルト): 記述した「すべての単語」を含むメディアのみ表示。
* `MODE:OR`: 記述した「いずれかの単語」を含むメディアを表示。

### 3. `config/exclude.txt`
除外したいパスに含まれる文字列を記述します。`include.txt` より優先されます。

### 4. ブックマークファイル (`bookmarks.csv` / 自動生成)
ブックマークしたファイルの情報が自動的に保存されます。
* 形式: `フォルダパス,ファイル名,選択していた設定ファイル名`
* 例: `C:\Users\User\Pictures,photo.jpg,folders.txt`

---

> **💻 高度な使い方**
> 独自のテキストファイルを引数として渡すことが可能です。
> `node server/server.js "my_folders.txt" "my_include.txt" "my_exclude.txt"`
> 
> また、ディレクトリパスを引数として渡すと「設定ファイル切り替えモード」になり、UI上からそのディレクトリ内のテキストファイルを複数選択して一括読み込みしたり、**内蔵エディタで直接編集**できるようになります。
> `node server/server.js "C:\MyConfigs"`
